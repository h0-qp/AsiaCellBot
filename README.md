# AsiaCellBot

بوت تلغرام (Pyrogram) للتحكم الكامل بحساب **Asiacell** العراق من داخل تلغرام:

- تسجيل دخول برقم آسياسيل + رمز OTP، مع دعم **حسابات متعددة** والتبديل الفوري بينها
- الرصيد والاشتراكات والعروض النشطة، تصفح الباقات والاشتراك الفعلي وإهداء باقة لرقم آخر
- باقات RED و YOOZ والتجوال، و **مستشار باقات ذكي** يمسح الكتالوج كاملًا ويرتّب حسب أفضل قيمة (السعر لكل كيكا)
- العجلة اليومية + تدوير تلقائي اختياري، خدمة شكراً (رصيد/إنترنت مقدم)
- شحن بكارت، تحويل رصيد، سجل الاستخدام (CDR) بتدفق OTP خاص، خطوطي، الإشعارات، الدعم والتذاكر
- مراقب انتهاء الرصيد/البيانات، تنبيه رصيد منخفض، تقرير أسبوعي، تغيير صورة الحساب، تصدير البيانات
- لوحة أدمن للإحصائيات والبث

## التشغيل

```bash
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
cp .env.example .env   # املأ التوكن وبيانات API
./run.sh               # مشرف يعيد التشغيل تلقائيًا
```

> ملفات الأسرار (`.env`، `data/sessions.json`، جلسات تلغرام) مستثناة من هذا المستودع قصدًا عبر `.gitignore`.
